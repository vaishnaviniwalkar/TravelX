# 🌍 Travel Destination Explorer
A visually rich, modern travel UI built using HTML and CSS for a frontend competition.

## ✨ Features
- Modern hero section with search bar  
- Destination cards with smooth hover animations  
- Best-time-to-visit indicators  
- Weather preview strip  
- Interactive map-inspired layout  
- Itinerary planner using glassmorphism  
- Contact form with floating labels  
- Fully responsive  
- Designed with multiple gradients and glowing UI effects  

## 🛠️ Technologies Used
- HTML5  
- CSS3 (Flexbox, Grid, Animations)

## 🎯 Purpose
This project was built for a CSS Showdown round to demonstrate:
- Creative UI/UX design  
- Responsive layout skills  
- Card-based interfaces  
- Visual animation work
